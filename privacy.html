개인정보처리방침

시행일: 2026년 10월 21일 · 대상 애플리케이션: Hermes (개인용 AI 비서)

본 개인정보처리방침은 개인용 애플리케이션 Hermes(이하 "본 앱")가 Google 사용자 데이터에 접근하고 이를 사용·저장·공유하는 방식을 설명합니다. 본 앱은 개발자 본인 1명이 자신의 Google 계정에 대해서만 사용합니다.

1. 접근하는 Google 사용자 데이터

사용자가 OAuth 동의 화면에서 승인한 경우에만 다음 범위에 접근합니다.

  • Gmail (gmail.readonly, gmail.send, gmail.modify): 메일 검색·조회·요약, 사용자가 지시한 메일 발송 및 답장, 읽음 표시·라벨 변경
  • Google 캘린더 (calendar): 일정 조회 및 등록
  • Google 드라이브 (drive): 파일 검색·조회·업로드·다운로드
  • Google 문서·스프레드시트 (documents, spreadsheets): 문서 작성·조회·편집
  • 연락처 (contacts.readonly): 주소록 조회

2. 데이터의 사용 목적

접근한 데이터는 사용자가 요청한 개인 업무(일정 확인, 메일 요약과 초안 작성, 문서 검색과 편집 등)를 수행하는 목적으로만 사용됩니다. 광고, 프로파일링, 사용자 행동 분석에 사용하지 않습니다.

3. 데이터의 저장과 보관

  • OAuth 인증 토큰은 사용자 본인의 Windows PC 내 로컬 폴더에만 저장됩니다.
  • 메일·일정 등 원본 데이터는 별도 서버에 복제·보관하지 않으며, 요청 처리 시점에만 메모리에서 사용됩니다.
  • 사용자가 요청한 결과물(요약, 초안, 메모)은 본인 PC의 로컬 파일로만 저장됩니다.
  • 토큰은 사용자가 언제든지 Google 계정 권한 설정에서 또는 본 앱의 철회 명령으로 삭제할 수 있습니다.

4. 제3자 제공 및 공유

본 앱은 Google 사용자 데이터를 제3자에게 판매·대여·공유하지 않습니다. 사용자가 선택한 AI 모델 제공업체에 요청을 보내는 경우, 해당 요청에는 사용자가 그 시점에 필요로 하는 최소한의 내용만 포함되며, 민감한 정보나 비공개 자료는 사용자의 승인 없이 외부로 전송하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

본 앱의 Google API 사용은 Google API Services User Data Policy를 준수하며, 여기에는 Limited Use 요구사항이 포함됩니다. 즉, Google 사용자 데이터는 사용자에게 공개된 목적 이외로 사용하지 않고, 광고 목적으로 사용하지 않으며, 사람이 열람하지 않습니다(사용자 본인이 요청한 경우 및 보안 목적의 예외는 제외).

6. 데이터 삭제 요청

사용자는 Google 계정 권한 설정에서 본 앱의 접근 권한을 즉시 철회할 수 있습니다. 철회 시 로컬에 저장된 토큰은 더 이상 유효하지 않게 되며, 관련 로컬 데이터 파일은 사용자가 직접 삭제할 수 있습니다. 삭제 요청은 eunsang26@gmail.com 으로도 가능합니다.
